## 📌 About the Project
**KinetiX** is a multifunctional, closed-ecosystem automation suite designed to eliminate routine tasks in Minecraft. Built from the ground up with cross-client compatibility in mind, it fully supports both **Java Edition (JE)** and **Bedrock Edition (BE)**.

As a completely standalone Desktop application with a modern UI, KinetiX does not inject into the game's memory (ensuring safety). Instead, it acts as a "smart" virtual player using screen analysis and action emulation.

## 🔥 Key Features
* 🎮 **Universal Compatibility** — Flawless operation on both Java Edition (JE) and Bedrock Edition (BE).
* 🎣 **Smart Automation** — AFK Fishing, Auto-Food (hunger-based), Background Mode support, and Anti-AFK.
* 📦 **Auto-Trader & Fast Crafter** — Automated villager trading and instant grid crafting.
* 🛡️ **Profile System** — Save configurations for different tasks and switch between them in one click.
* 🖥️ **Built-in Hardware Monitor** — Track CPU and RAM usage directly in the app header.
* 💬 **Discord Rich Presence** — Native integration to show your gaming status in Discord.
* ⚙️ **Custom Binds & Hotkeys** — Flexible hotkey configuration (F6, F7, F8, etc.).
* ☁️ **OTA Updates** — The application automatically checks for updates and installs them over the air.

## 🚀 Installation
1. Navigate to the **[Releases](../../releases/latest)** section on the side of this page.
2. Download the latest `Kinetix_Setup.exe` file.
3. Run the installer and follow the on-screen instructions.

> [!NOTE]
> *On the first launch, Windows Defender (SmartScreen) might show a warning. This is completely normal for private software without a paid digital signature. Simply click "More info" -> "Run anyway".*

## 📌 Про проєкт
**KinetiX** — це закритий софт для автоматизації рутини в Minecraft. Програма розроблялася з урахуванням особливостей різних клієнтів, тому вона гарантовано підтримує як **Java Edition (JE)**, так і **Bedrock Edition (BE)**. 

Це повністю незалежний Desktop-додаток з сучасним інтерфейсом, який не втручається в пам'ять гри (що робить його безпечним) і діє як "розумний" віртуальний гравець за допомогою аналізу екрану та емуляції дій.

## 🔥 Головні Фічі
* 🎮 **Універсальність** — повноцінна робота на Java Edition (JE) та Bedrock Edition (BE).
* 🎣 **Смарт-Автоматизація** — АФК-рибалка, Авто-їжа (по голоду), підтримка фонового режиму та Anti-AFK.
* 📦 **Auto-Trader & Fast Crafter** — автоматична торгівля з жителями та миттєвий крафт у сітці.
* 🛡️ **Система Профілів** — зберігай налаштування для різних задач та перемикайся між ними в один клік.
* 🖥️ **Вбудований Моніторинг** — слідкуй за навантаженням на CPU та RAM прямо в шапці програми.
* 💬 **Discord Rich Presence** — нативна інтеграція твого ігрового статусу в Discord.
* ⚙️ **Custom Binds & Hotkeys** — гнучке налаштування гарячих клавіш (F6, F7, F8 тощо).
* ☁️ **OTA Updates** — програма автоматично перевіряє наявність оновлень і встановлює їх по повітрю.

## 🚀 Встановлення
1. Перейдіть у розділ **[Releases](../../releases/latest)** збоку на цій сторінці.
2. Завантажте найновіший файл `Kinetix_Setup.exe`.
3. Запустіть інсталятор та дотримуйтесь інструкцій.

> [!NOTE]
> *При першому запуску Windows Defender може видати попередження (SmartScreen). Це нормально для приватного софту без цифрового підпису. Просто натисніть "Докладніше" -> "Виконати в будь-якому випадку".*
